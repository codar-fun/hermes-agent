# 02 · 命令行与交互

Hermes 有两类命令：
1. **`hermes <子命令>`** —— 终端里的 CLI 子命令（管理、配置、启动服务）。
2. **`/<斜杠命令>`** —— 进入会话后输入的斜杠命令（控制当前对话）。很多斜杠命令在 CLI 和消息平台两边通用。

---

## 1. `hermes` 子命令

```bash
hermes                     # 默认：进入交互式对话
hermes chat                # 同上
hermes --tui               # 启动 Ink TUI（或 HERMES_TUI=1）

hermes model [provider:model]   # 选择/切换模型与供应商
hermes tools               # 配置启用的工具/工具集
hermes config set          # 设置单个配置项
hermes setup [--portal]    # 完整设置向导（--portal 走 Nous Portal）

hermes gateway             # 前台运行消息网关
hermes gateway setup       # 配置各消息平台
hermes gateway start|stop|restart|status   # 后台服务管理
hermes gateway install|uninstall           # 安装/卸载为系统服务
hermes gateway logs        # 查看网关日志

hermes cron                # 管理定时任务
hermes cron list|status    # 列表 / 调度器状态

hermes mcp                 # 管理 MCP 服务器（交互式 picker）
hermes mcp list|add|remove|test|configure

hermes portal [login|info|tools|open]   # Nous Portal 账户与工具网关
hermes sessions browse     # 带搜索的会话选择器
hermes acp                 # 作为 ACP 服务器供编辑器集成（VS Code / Zed / JetBrains）
hermes dashboard           # 启动本地仪表盘（SPA + 内嵌 TUI）

hermes status              # 各组件状态
hermes doctor              # 体检配置与依赖
hermes logs                # 查看日志
hermes update              # 升级
hermes uninstall           # 卸载
hermes claw migrate        # 从 OpenClaw 迁移
hermes version             # 版本号
```

> 提示：`hermes <子命令> --help` 可查看该子命令的全部选项。

## 2. 斜杠命令全表

进入会话后输入。下表按类别整理（源自 `hermes_cli/commands.py` 的中央注册表，CLI / 网关 / Telegram 菜单 / 自动补全都由它自动派生）。

### 会话（Session）

| 命令 | 别名 | 作用 |
|------|------|------|
| `/new` | `/reset` | 开新会话（全新会话 ID 与历史）|
| `/clear` | | 清屏并开新会话 |
| `/history` | | 显示对话历史 |
| `/save` | | 保存当前会话 |
| `/title <标题>` | | 给会话设标题 |
| `/resume <名字>` | | 恢复一个命名会话 |
| `/sessions` | | 浏览并恢复历史会话 |
| `/retry` | | 重发上一条消息 |
| `/undo [N]` | | 回退 N 个用户回合并重提（默认 1）|
| `/branch` | | 从当前会话分叉，探索另一条路径 |
| `/compress [here N]` | | 压缩上下文（`here N` 保留最近 N 回合）|
| `/rollback` | | 列出/恢复文件系统检查点 |
| `/snapshot` | | 创建/恢复 Hermes 配置状态快照 |
| `/stop` | | 杀掉所有后台进程 |
| `/background <提示>` | `/bg` | 在后台跑一个提示 |
| `/queue <提示>` | | 排队下一回合的提示（不打断当前）|
| `/steer <消息>` | | 在下次工具调用后注入消息（不打断）|
| `/goal <目标>` | | 设定跨回合持续推进的长期目标 |
| `/subgoal` | | 给当前目标增删判定条件 |
| `/agents` | | 显示活跃智能体与运行中任务 |
| `/handoff` | | 把会话移交给某消息平台 |
| `/restart` | | 排空活跃任务后优雅重启网关 |

### 配置（Configuration）

| 命令 | 作用 |
|------|------|
| `/config` | 显示当前配置 |
| `/model [provider:model]` | 切换本会话模型 |
| `/personality [名字]` | 套用预定义人格 |
| `/reasoning` | 管理推理强度与显示 |
| `/fast` | 切换 Fast 模式（OpenAI 优先处理 / Anthropic Fast）|
| `/yolo` | 切换 YOLO 模式（跳过所有危险命令审批）⚠ |
| `/verbose` | 循环切换工具进度显示：off→new→all→verbose |
| `/voice` | 切换语音模式 |
| `/skin [名字]` | 切换显示主题 |
| `/statusbar` | 切换上下文/模型状态栏 |
| `/busy` | 控制工作中按 Enter 的行为 |
| `/codex-runtime` | 切换 OpenAI/Codex 模型的 app-server 运行时 |

### 工具与技能（Tools & Skills）

| 命令 | 作用 |
|------|------|
| `/tools [list\|enable\|disable] [名...]` | 管理工具 |
| `/toolsets` | 列出可用工具集 |
| `/skills` | 搜索、安装、查看、管理技能 |
| `/<技能名>` | 直接调用某个技能（如 `/deepscan`）|
| `/bundles` | 列出技能捆绑包 |
| `/cron` | 管理定时任务 |
| `/curator` | 后台技能维护（status / run / pin / archive）|
| `/kanban` | 多 Profile 协作看板 |
| `/browser` | 通过 CDP 连接你正在用的 Chromium 浏览器 |
| `/reload` | 把 `.env` 变量重载进当前会话 |
| `/reload-mcp` | 从配置重载 MCP 服务器 |
| `/reload-skills` | 重新扫描 `~/.hermes/skills/` |
| `/plugins` | 列出已安装插件及状态 |

### 信息（Info）

| 命令 | 作用 |
|------|------|
| `/help` | 显示可用命令 |
| `/commands` | 分页浏览所有命令与技能 |
| `/usage` | 当前会话的 Token 用量与速率限制 |
| `/insights [--days N]` | 用量分析与统计 |
| `/status` | 会话信息 |
| `/whoami` | 显示你的斜杠命令权限（admin / user）|
| `/profile` | 显示当前 Profile 名与 home 目录 |
| `/platforms` | 网关/消息平台状态 |
| `/copy` `/paste` `/image` | 复制上条回复 / 粘贴剪贴板图片 / 附加本地图片 |
| `/update` | 升级 Hermes |
| `/debug` | 上传调试报告并拿到可分享链接 |

### 网关专用（消息平台）

| 命令 | 作用 |
|------|------|
| `/sethome` | 把当前聊天设为 home 频道（定时任务投递目的地）|
| `/approve` `/deny` | 批准/拒绝待处理的危险命令 |
| `/footer` | 切换最终回复的网关运行时元信息页脚 |
| `/platform` | 暂停/恢复/列出某失败平台 |

### 退出

| 命令 | 别名 | 作用 |
|------|------|------|
| `/quit [--delete]` | `/exit` | 退出 CLI（`--delete` 同时删除会话历史）|

> CLI 与网关的「打断」方式不同：**CLI** 用 `Ctrl+C` 或直接发新消息；**消息平台**用 `/stop` 或直接发新消息。

## 3. 终端 UI 的两种形态

- **经典 CLI（`hermes`）**：基于 prompt_toolkit + Rich，含多行编辑、斜杠命令自动补全、流式工具输出、动画 spinner（`agent/display.py`）。
- **Ink TUI（`hermes --tui`）**：TypeScript（Ink/React）渲染屏幕，Python（`tui_gateway`）负责会话/工具/模型调用，二者通过 stdio 上的 JSON-RPC 通信。`hermes dashboard` 的聊天页内嵌的就是真实的 `hermes --tui`。

---

## 4. 快速命令（quick_commands）与人格

- **人格**：在 `config.yaml` 的 `agent.personalities` 里定义，用 `/personality <名字>` 切换。
- **快速命令**：用户自定义的 `quick_commands`，会作为斜杠命令出现在补全里。
- **技能斜杠命令**：`~/.hermes/skills/` 下每个技能都会注册为 `/<技能名>`；它是以**用户消息**注入（而非系统提示），以保留提示缓存。
