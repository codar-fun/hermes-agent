# 04 · 模型与提供商

Hermes **不锁定任何模型**：一个统一的对话循环可以接入任意 OpenAI 兼容（或原生适配）的供应商，用 `hermes model` 随时切换，不改一行代码、不绑死端点。

---

## 1. `hermes model` —— 选择与切换

```bash
hermes model                              # 交互式选择器
hermes model <模型名>                      # 同供应商内切模型
hermes model <模型名> --provider <供应商>   # 同时切供应商和模型
hermes model --global                     # 存为全局默认（而非仅本会话）
hermes model --refresh                    # 刷新本地模型目录缓存后再列
```

会话内也可用斜杠命令 `/model [provider:model]`。

### 模型简称（alias）

为常用模型提供短名，自动解析为当前供应商下的最新版本：

| 简称 | 指向 |
|------|------|
| `sonnet` / `opus` / `haiku` | 最新 Claude Sonnet / Opus / Haiku |
| `gpt5` / `gpt` | 最新 GPT |
| `gemini` | 最新 Gemini |
| `deepseek` | 最新 DeepSeek |
| `grok` | xAI Grok |
| `qwen` | 最新 Qwen（通义）|
| `kimi` | 最新 Kimi |

### 模型目录来源

- 内置静态列表（`hermes_cli/models.py` 的 `CANONICAL_PROVIDERS` / `_PROVIDER_MODELS`）
- 远程清单：`https://hermes-agent.nousresearch.com/docs/api/model-catalog.json`
- OpenRouter 实时目录：`https://openrouter.ai/api/v1/models`
- 本地缓存：`~/.hermes/cache/model_catalog.json`（约 1 小时 TTL，`--refresh` 可强刷）

> 共有 30+ 个内置供应商。`hermes model` 的选择器里会按归组展示（如 google = AI Studio + Code Assist OAuth；openai = Codex CLI + 直连 API）。

### 自定义 / 本地端点

任何 OpenAI 兼容端点（Ollama、vLLM、自建网关）都能接：

```yaml
# config.yaml
custom_providers:
  - name: "My Ollama"
    base_url: "http://localhost:11434/v1"
    models:
      mistral: {}
      llama3: {}
```

或在 `providers:` 段里声明 Key 取自哪个环境变量：

```yaml
providers:
  my-endpoint:
    name: "My Endpoint"
    url: "https://api.example.com/v1"
    key_env: "CUSTOM_API_KEY"
```

## 3. Nous Portal（一份订阅省去多套 Key）

[Nous Portal](https://portal.nousresearch.com) 用一份订阅覆盖模型 + 工具网关，省去分别申请「模型、搜索、图像、TTS、云浏览器」的麻烦。

```bash
hermes setup --portal       # 一键：OAuth 登录 + 设为 Nous + 打开工具网关
hermes portal               # 或单独走 Portal 登录
hermes portal info          # 查看登录状态与工具网关路由
hermes portal tools         # 列出工具网关目录
hermes portal open          # 打开订阅页
```

- **登录方式**：OAuth 设备码流程（访问 Portal、输入验证码），Token 存入 `~/.hermes/auth.json` 的凭据池（不进环境变量）。
- **工具网关**给你的能力（按订阅授权）：网页搜索（Firecrawl）、图像生成（FAL）、云浏览器（Browser Use）、云终端（Modal）、TTS（OpenAI Audio）。
- **300+ 模型**：用 `/model <名字>` 任选。免费档用户只看到免费模型（零成本），付费档看到全部。
- **成本保护**：当供应商设为 Nous 但没指定模型时，默认落到便宜的 `deepseek/deepseek-v4-flash`，绝不静默升级到旗舰模型。

## 4. 回退与辅助模型

### 回退链（智能路由）

主供应商失败时自动按序回退：

```yaml
fallback_providers:
  - openrouter      # 主
  - anthropic       # 次（openrouter 失败时用）
  - nous            # 再次
```

### 辅助（侧）模型

把「视觉理解、上下文压缩、网页抽取摘要、审批决策、标题生成、MCP sampling」等侧任务交给单独的（通常更便宜的）模型：

```yaml
auxiliary:
  vision:
    provider: "auto"               # auto 会按已认证供应商顺序尝试
    model: "google/gemini-3-flash"
    timeout: 120
  compression:
    provider: "auto"
    model: ""
  approval:
    provider: "auto"
    model: ""                       # 建议 haiku / flash 这类便宜模型
```

- `provider: "auto"` 会尝试已认证的供应商，兜底到 `openrouter:google/gemini-3-flash-preview`。
- 解析顺序见 `agent/auxiliary_client.py::_resolve_auto`。
- 需要 OpenRouter 路由偏好时可加 `extra_body`：

```yaml
auxiliary:
  compression:
    provider: openrouter
    model: openrouter/pareto-code
    extra_body:
      provider:
        order: [anthropic, google]
        sort: throughput     # price / latency / throughput
```

## 5. api_mode 是怎么选的

Hermes 用一个同步循环对接所有供应商，差异隔离在 `agent/transports/` 与各适配器里，由 `api_mode` 决定具体协议（见 `agent/agent_init.py`）：

1. 显式指定的 `api_mode` 优先；
2. 否则按供应商/URL 探测：Anthropic → `anthropic_messages`，Bedrock → `bedrock_converse`，OpenAI Codex / xAI → `codex_responses`，URL 以 `/anthropic` 结尾 → `anthropic_messages`；
3. 模型触发升级：GPT-5.x 自动升到 `codex_responses`（除非显式覆盖）；
4. 兜底：`chat_completions`。

常见适配器：`anthropic_adapter.py`、`bedrock_adapter.py`、`codex_responses_adapter.py`、`gemini_native_adapter.py` / `gemini_cloudcode_adapter.py`、`azure_identity_adapter.py`。

## 6. 凭据池与多 Key 故障转移

同一供应商可登记多个凭据，自动轮换：见 `agent/credential_pool.py`。来源包括环境变量、Claude Code 凭据、Anthropic / xAI / MiniMax OAuth、`gh` CLI、配置等。某 Key 限额或失效时会标记冷却并切换到下一个。
