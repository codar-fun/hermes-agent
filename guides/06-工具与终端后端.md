# 06 · 工具与终端后端

Hermes 的能力来自 **80+ 个工具**。工具按「工具集（toolset）」分组启用，命令/代码执行可以落在六种**终端后端**之一（本地 shell → 云端无服务器沙箱）。

> 📖 需要工具集完整目录、各后端逐一的精确配置键（Docker/SSH/Modal/Daytona/Singularity）、`execute_code` 沙箱细节、委派子智能体与输出限制？见独立文档 [13 · 工具与终端后端详解](./13-工具与终端后端详解.md)。本文为概览。

---

## 1. 管理工具

```bash
hermes tools                # 交互式配置启用哪些工具/工具集
```

会话内：

```text
/tools list                 # 列出当前可用工具
/tools enable <名...>       # 启用
/tools disable <名...>      # 禁用
/toolsets                   # 列出可用工具集
```

### 工具集（toolset）概念

- 工具集是一组工具的命名集合，可**组合嵌套**（`toolsets.py` 的 `TOOLSETS`，`resolve_toolset()` 递归展开并处理环路/菱形依赖）。
- `_HERMES_CORE_TOOLS` 是所有平台共享的核心工具包，每个平台的基础工具集都继承它。
- 平台工具集如 `hermes-cli`、`hermes-telegram`、`hermes-discord`…；`hermes-gateway` 是所有平台工具集的并集。
- 工具只有名字出现在某个工具集里才会**暴露给智能体**——自动发现只负责导入注册 schema。

### 渐进式披露（progressive disclosure）

当非核心工具（MCP / 插件工具）数量超过上下文预算时，它们会藏到三个桥接工具背后：`tool_search`（搜目录）、`tool_describe`（看 schema）、`tool_call`（调用）。这样不会用一大堆工具 schema 撑爆上下文。

## 3. 终端后端（命令在哪执行）

`terminal` 和 `execute_code` 在哪运行，由 `config.yaml` 的 `terminal.backend` 决定。六种后端共享统一抽象（`tools/environments/base.py` 的 `BaseEnvironment`，spawn-per-call 模型，每次命令前重新加载会话快照，跨命令保持 CWD）。

| 后端 | 值 | 说明 |
|------|-----|------|
| 本地 | `local` | 直接在宿主机子进程执行（默认）|
| Docker | `docker` | 每条命令在容器里跑，支持镜像/挂载/资源限制 |
| SSH | `ssh` | 远程主机执行，经 rsync/sftp 同步文件 |
| Singularity | `singularity` | Singularity/Apptainer 容器（HPC 常用）|
| Modal | `modal` | Modal 云沙箱；**空闲休眠、按需唤醒**，闲时几乎零成本 |
| Daytona | `daytona` | Daytona 云沙箱；同样支持无服务器持久化 |

```yaml
terminal:
  backend: "docker"
  docker_image: "nikolaik/python-nodejs:python3.11-nodejs20"
  docker_mount_cwd_to_workspace: true
  timeout: 180
```

> Modal / Daytona 的「休眠—唤醒」让你能把智能体环境放在云上，闲置时几乎不花钱、用时秒级唤醒。这也是 README 强调「不绑死你的笔记本」的底层支撑。

## 4. 委派与并行

- **`delegate_task`**：派生隔离的子智能体（无父级历史、独立 task_id、受限工具集）跑并行工作流。受 `config.yaml` 的 `delegation.*` 控制（并行数、迭代预算、嵌套深度）。
- **`execute_code`**：让模型写一段 Python，通过 RPC（本地 UDS / 远程文件）调用受限工具集，把「搜索→抽取→写文件」这类多步流水线收敛成一次零上下文成本的回合。其迭代不计入主预算（会退还）。
- **`/agents`** 查看活跃子智能体与运行中任务；**`/stop`** 杀掉后台进程。

## 5. 浏览器工具

```text
/browser        # 通过 CDP 连接你正在用的 Chromium 系浏览器
```

后端可选：本地 Chromium（默认）、Browserbase 云、Browser Use 云。页面以无障碍树（accessibility tree）的文本形式呈现给模型，`browser_vision` 走截图 + 视觉分析，`browser_cdp` 做高级自动化。
