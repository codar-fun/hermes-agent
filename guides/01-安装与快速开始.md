# 01 · 安装与快速开始

本文介绍如何安装 Hermes Agent、完成首次配置、开始第一次对话，并了解它在磁盘上的目录结构。

---

## 1. 系统要求

- **Python 3.11 – 3.13**（不支持 3.14；安装器会自动装好）
- **Node.js ≥ 20**（浏览器工具、TUI、桌面端需要）
- 外部命令：`ripgrep`（代码搜索）、`ffmpeg`（语音/媒体）——安装器会一并处理
- 支持平台：Linux、macOS、WSL2、原生 Windows、Android(Termux)

---

## 2. 一键安装

### Linux / macOS / WSL2 / Termux

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc      # 重新加载 shell（zsh 用户：source ~/.zshrc）
hermes                # 启动！
```

安装器会自动准备 uv、Python 3.11、Node.js、ripgrep、ffmpeg。

### Windows（原生 PowerShell，无需 WSL）

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

会额外下载一个便携版 Git Bash（MinGit，解压到 `%LOCALAPPDATA%\hermes\git`，与系统 Git 完全隔离，无需管理员权限）。Hermes 用它来执行 shell 命令。若系统已装 Git，则直接复用。

> **说明**
> - 原生 Windows 安装在 `%LOCALAPPDATA%\hermes`；WSL2 安装在 `~/.hermes`（与 Linux 一致）。
> - Termux 安装的是精简版 `.[termux]`，因为完整 `.[all]` 会拉入与 Android 不兼容的语音依赖。
> - 唯一需要 WSL2 的功能是浏览器仪表盘里的聊天面板（依赖 POSIX PTY）。

---

## 3. 从源码安装（贡献者 / 开发者）

```bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
./setup-hermes.sh     # 安装 uv、建 .venv、装 .[all]、软链 ~/.local/bin/hermes
./hermes              # 自动识别 venv，无需先 source
```

等价的手动步骤：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv venv .venv --python 3.11
source .venv/bin/activate
uv pip install -e ".[all,dev]"
scripts/run_tests.sh   # 跑测试套件
```

> **依赖分层**：核心依赖被**精确钉版本**（供应链加固）。供应商专属依赖（如 `anthropic`、`firecrawl-py`、`edge-tts`）是**惰性安装**的——你在 `hermes tools` 里选用某后端时才会装（见 `tools/lazy_deps.py`）。

---

## 4. 首次配置

安装后有两条路：

### 路线 A：Nous Portal 一键（最省事）

如果你不想分别申请「模型、网页搜索、图像生成、TTS、云浏览器」五套 Key，[Nous Portal](https://portal.nousresearch.com) 用一份订阅全部覆盖：

```bash
hermes setup --portal
```

它会通过 OAuth 登录、把供应商设为 Nous、打开工具网关。随时用 `hermes portal info` 查看接入状态。详见 [04 · 模型与提供商](./04-模型与提供商.md)。

### 路线 B：自备 API Key

```bash
hermes setup        # 完整向导：模型、工具、网关一次配好
# 或分步：
hermes model        # 选供应商和模型
hermes tools        # 选启用哪些工具
```

把 API Key 填进向导，或手动写入 `~/.hermes/.env`。

---

## 5. 第一次对话

```bash
hermes              # 进入经典终端 UI（prompt_toolkit + Rich）
hermes --tui        # 进入 Ink 全功能 TUI（也可设 HERMES_TUI=1）
```

进入后直接打字提问即可。常用操作：

- 输入 `/help` 看全部斜杠命令
- `Ctrl+C` 或直接发新消息打断当前任务
- `/model` 换模型，`/new` 开新会话，`/quit` 退出

---

## 6. 目录结构（`~/.hermes/`）

所有用户数据都在 **`~/.hermes/`**（路径感知 Profile，见 [03 · 配置详解](./03-配置详解.md)）：

```
~/.hermes/
├── config.yaml         # 全部非密钥设置（也可能叫 cli-config.yaml）
├── .env                # 仅密钥：API Key、Token、密码
├── auth.json           # OAuth 凭据池（Nous / Anthropic / xAI 等，自动管理）
├── state.db            # SQLite 会话库（FTS5 全文检索）
├── skills/             # 技能（程序性记忆）
│   └── .hub/           # Skills Hub 安装记录与审计日志
├── plugins/            # 用户安装的插件
├── skins/              # 自定义主题
├── pairing/            # 各平台 DM 配对状态
├── cron/               # 定时任务定义
├── logs/               # agent.log / errors.log / gateway.log
└── cache/              # 模型目录缓存等
```

- **配置文件**：`~/.hermes/config.yaml`（设置）+ `~/.hermes/.env`（密钥）
- **日志**：`hermes logs [--follow] [--level ...] [--session ...]` 浏览

---

## 7. 常用维护命令

```bash
hermes update       # 升级到最新版
hermes doctor       # 体检：检查配置与依赖
hermes status       # 查看各组件状态
hermes logs         # 查看日志
hermes uninstall    # 卸载
```

### 从 OpenClaw 迁移

```bash
hermes claw migrate              # 交互式迁移（完整预设）
hermes claw migrate --dry-run    # 预览将迁移什么
hermes claw migrate --preset user-data   # 不含密钥
```

会导入：人格文件 SOUL.md、记忆（MEMORY.md / USER.md）、用户技能、命令白名单、消息平台配置、白名单内的 API Key、TTS 资源、AGENTS.md 工作区指令。
